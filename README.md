# 高考年华 · Highschool Runtime

一套安静、专注的高考真题模考工作台。Windows 桌面应用，内置真题与模拟卷，支持离线模考、自动判分与成绩复盘，所有记录保存在本机。

## 功能

- **题库**：110 套试卷，覆盖语文、数学、英语、物理、化学、生物、政治、历史、地理九科。可按学科、地区、年份、卷型筛选，也能直接搜索卷名和标签。
- **模考**：倒计时与答题卡，答案实时保存；未答题目在交卷前会提示，中途离开可以暂停交卷，下次回到今日页继续。
- **判分**：单选、多选、填空按参考答案自动判分，解答题对照解析自评，交卷后立即得到总分与得分率。
- **复盘**：逐题回看作答、参考答案与解析；成绩页给出总分走势、各科均分、连续学习天数和每周节奏。
- **今日**：高考倒计时、推荐一场练习、最近成绩与待完成的评卷。
- **本地优先**：不需要账号，不连接云端，作答记录只写入本机浏览器存储。

## 快速开始

需要 Windows 10/11 和 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

安装完成后也可以直接双击 `启动高考年华.bat`，首次启动会自动构建缺少的产物。

以桌面窗口运行构建后的版本：

```bash
npm start
```

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 同时启动 Vite 与 Electron，修改代码即时刷新 |
| `npm run build` | 类型检查并生成 `dist/` |
| `npm start` | 构建后以桌面窗口运行 |
| `npm run preview` | 只在浏览器里预览前端 |
| `npm run sync:papers` | 从 `.tmp` 下的公开题库原始数据重新生成试卷，仅供维护题库使用 |

## 目录结构

```
src/
  pages/          今日、题库、试卷详情、考试、复盘、成绩等页面
  components/     标题栏、侧栏、弹窗、Markdown 与公式渲染
  lib/            试卷解析、判分、统计、本地存储
  data/papers/    试卷 Markdown，带 YAML 头信息
public/
  paper-assets/   试卷插图与公式图片
electron/         主进程与窗口控制
scripts/          开发脚本与试卷生成脚本
```

## 添加试卷

试卷是带 YAML 头信息的 Markdown 文件，放进 `src/data/papers/` 后重新构建就会自动收录。正文用 `## 分节` 和 `### 第 N 题` 划分结构，公式用 LaTeX（行内 `$...$`，独立 `$$...$$`），插图放在 `public/paper-assets/` 并以相对路径引用。头信息包含学科、地区、年份、卷型、时长、总分，以及每道题的题型、分值、参考答案与评分方式，具体写法可以参考现有试卷。

## 题库来源

- 70 套真题选编来自 [GAOKAO-Bench 公开真题集](https://github.com/rainewhk/gaokao)，依据 Apache-2.0 许可使用。
- 13 套数学卷来自公开高考数学真题汇编的 PDF 原卷。
- 27 套模拟卷由 2016–2024 年公开真题重新组卷，仅用于限时训练，不代表任何命题预测。
- 试卷插图截取自公开原卷，仅用于试题呈现，相关权利归原权利人；如权利人认为使用不妥，可联系删除。

## 数据与隐私

作答记录、成绩和个人设置保存在本机 localStorage，键名以 `highschool-runtime.` 开头，不会上传到任何服务器。清除应用数据会同时清空这些记录。日常使用不需要网络。
